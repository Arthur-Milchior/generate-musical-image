Generates images for the harmonica. Smaller/less developed than the other instrument packages — see
`__init__.py` for the current generation loop and `images/` for pre-rendered output. Run via
`python3 -m instruments.harmonica` from `src/` (see [`../../README.md`](../../README.md)).

There is also a legacy top-level `src/harmonica/` folder (just an `images/` directory) that predates this
package under `instruments/`; the code here is the current one.
